# 掘墓的EVE更新助手 2.5.0

开发者：WC飞机杯大王掘墓。Windows 10/11 x64 便携程序，无需另外安装.NET。

[下载正式版](https://github.com/RyoseDarme/eve-update-helper/releases/latest) · [项目源码](https://github.com/RyoseDarme/eve-update-helper)

## 本版解决的问题

旧快速档按TCP延迟选少量节点，主资源找到3个可用结果就停止，其他域名找到第一个可用结果就停止。可用的节点可能只有约1 MiB/s，不能据此判断没有更快线路。本版改变搜索和比较顺序，速度仍按网络实际传输字节计量，没有人为提高显示数值。

1. 最多2048个CloudFront网段抽样IP，加上DNS和当前节点。全池先各连1次，仅复测128个候选及可连接的本机候选；128个名额同时保留低延迟和不同网段，避免一个网段挤占候选池。
2. 主资源跨网段短测最多12个候选，总预算最多36秒。逐个测试，每个请求最多4秒，其中下载窗口最多2秒；按实际初测下载速度排序。这些结果只供筛选，不能直接应用。
3. 排名靠前者持续验证10秒，再完成3次小请求。如果完整测速明显低于其他候选初速，且剩余时间足够，最多再完整确认一个资源候选。
4. 其他四个下载域名各自持续验证8秒并完成小请求。游戏文件域名优先验证已测得较快的资源候选，启动器自身更新域名保留自己的当前节点作优先基线，均使用真实域名独立验证。
5. 五个必需域名全部通过后，如果还有至少28秒，继续比较较慢域名的其他候选；替代节点失败时保留原来的有效结果。

默认快速档仍最多180秒；标准最多480秒，精校准不限时。短测只有有限采样窗口，排名可能受缓存和线路波动影响，推荐值须以完整持续测速为准。本版改善搜索方式，不承诺任何线路必定出现某个速度或找到全网最快节点。

## 使用

解压运行EXE，默认快速档，点击“开始测速”。表中“初测”只用于比较；只有五个必需域名都完整通过，才能应用。未通过时保留现有hosts；可选标准档扩大搜索。

测速完成后，从系统托盘完全退出EVE启动器，再点击“应用节点”并允许管理员权限。应用直接复用本轮结果，不重复下载测速；校验结果完整性与30分钟有效期、备份整理整个hosts、回读核对每域只有一条正确IP，再刷新DNS。启动器运行时拒绝应用。更换网络或代理后需重新测速。

保留管理块外旧记录清理、两个-fallback独立验证、备份恢复、下载诊断、VPN域名导出和GitHub Releases更新提醒。不会删除账号、SharedCache或游戏设置。节点测试走直连，更新提醒遵循系统代理；打开系统代理不等于EVE下载器一定经过该代理。

## 验证与构建

174项离线检查通过，新增回归场景包含：低延迟节点只有1 MiB/s但更高延迟节点更快；较高延迟的其他网段不会被挤出候选；短测峰值不能直接应用；第一个域名结果较慢时继续比较；短测很快但完整下载仅1 MiB/s时确认第二候选。测试中的80 MiB/s是模拟数据，不能当作本机实际测速结果。

本轮只做4个已有IP的有限短测和其中一个候选的完整验证，没有重复整轮联网扫描。具体实测结果见发行包“验证报告”。没有因检测到版本更新而自动应用节点或替换EXE。

Windows安装.NET 8 SDK后运行build.ps1；或执行：

```powershell
dotnet publish EveUpdateHelper.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```
